# 🎬 Youseif Films — النسخة المصححة

نسخة مبنية على الكود الأصلي مع الحفاظ على وظائف البوت الأساسية، مع إصلاح التنظيم والتشغيل المباشر.

## أهم الإصلاحات
- 🎬 الأفلام: بلد/لغة → النوع → القسم → الأفلام.
- 📺 المسلسلات: بلد/لغة → النوع → القسم → المسلسلات → المواسم → الحلقات.
- 📡 القنوات: نوع القنوات → الباقة → القنوات.
- ⚽ مثال: رياضية → باقات → قنوات الباقة → مشاهدة مباشرة، مع أزرار جودة فقط عندما توجد نسخ متعددة ظاهرة فعلياً.
- 🔗 روابط التشغيل هي روابط Xtream الأصلية المباشرة، مثل `/live/...m3u8` أو `/movie/...mp4` أو `/series/...mp4`، بدون Worker أو مشغل خارجي أو بارامترات إضافية.
- 🖼️ كارت العمل يعرض البوستر والتفاصيل والتقييم والسنة والمدة عند توفرها.
- 🌐 يتم عرض الاسم العربي والاسم الإنجليزي/الأصلي عند توفرهما.
- 🎞️ TMDB يدعم `TMDB_API_KEY` و`API_Read_Access_Token`، ويضع Bearer Token في `Authorization`.
- 👑 `ADMIN_ID` من Secrets/Environment ويحدد المالك فعلياً.
- 🔞 قسم محتوى الكبار للمالك فقط. المستخدم العادي يرى رسالة للتواصل مع المطور ولا يحصل على كلمة المرور.
- 🚫 القنوات الدينية غير الإسلامية محجوبة من التصنيفات والبحث والعرض للمستخدمين.
- 🔍 البحث والمفضلة والعشوائي ولوحة الأدمن محفوظة.
