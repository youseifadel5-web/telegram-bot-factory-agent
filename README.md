# Unified Telegram Bot

## الهيكل
- `bot.py` هو البوت الأساسي والـpolling الوحيد.
- `Add bot/` هو المكان الوحيد لإضافة البوتات الفرعية.
- كل ملف `.py` مباشر داخل `Add bot/` يعتبر بوتًا فرعيًا. اسم الملف لا يهم.
- لا تحتاج لإنشاء مجلد أو ملف إعداد إضافي للبوت الفرعي.

## البوابة
- `🎬 بوت سينماء`: يعرض كل البوتات المفعلة الموجودة في `Add bot/`.
- `🔍 بحث`: يبحث في كل البوتات المفعلة التي توفر hook باسم `search`.
- `👑 لوحة التحكم`: تظهر للـ`ADMIN_ID` فقط في البوابة الخارجية.

## API البوت الفرعي
لكي يعمل ملف `.py` مع المضيف بدون polling مستقل، يمكنه توفير:
- `PLUGIN_NAME` / `PLUGIN_BUTTON` اختياريًا.
- `open_plugin(call, context)` لفتح واجهته.
- `handle_callback(call, context)` لمعالجة أزراره.
- `handle_message(update, context)` لمعالجة الرسائل.
- `search(query, context)` اختياريًا لإدخاله في البحث الموحد.

يمكن أن تكون كل هذه الوظائف داخل **ملف Python واحد فقط**.

> مهم: ملف البوت الفرعي لا يجب أن يبدأ `polling` أو `run_polling()` بنفسه، لأن `bot.py` الأساسي هو المسؤول عن polling باستخدام الـToken الموحد.
