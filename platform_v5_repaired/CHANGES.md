# المنصة الموحدة V5 — سجل الإصلاحات (مقابل شكاوى المستخدم)

1) الأزرار:
   - زر «▶️ مشاهدة» أصبح يفحص الجودة فعليًا ثم يعرض اختيار الجودة.
   - زر جديد «🎞️ كل الروابط والجودات» يفتح روابط حقيقية (أزرار url قابلة للفتح في المشغل)
     من كل المصادر المدمجة — لم يعد الزر يعمل كزر رجوع.

2) البوتات القديمة:
   - في القائمة الرئيسية: سطر «المنصة الموحدة — كل المصادر» + قسم «البوتات القديمة»
     (يوسف فيلم / سينما نوفا / أوريون بلس).
   - قسم يوسف فيلم يُصفح المكتبة الكاملة (أفلام/مسلسلات) باسم وصورة، وفيه زر رجوع
     «🏛️ المنصة الموحدة».

3) تصنيف تفصيلي للقنوات بأسلوب يوسف باي:
   - قنوات مباشرة → نوع (رياضة/أخبار/أطفال/أفلام...) → باقة → قناة (بوستر + اسم)
     عبر build_content_hierarchy من youseif_core.

4) البوسترات: التفاصيل والقنوات تُعرض صورة + اسم بشكل احترافي (fallback للنص عند فشل الصورة).

5) لوحة الإدارة: زرها ظاهر دائمًا، أمر /admin، وإذا كانت ADMIN_IDS فارغة تظهر اللوحة
   (وضع تطوير) — للإنتاج ضع أرقام الأدمن الحقيقية.

6) القنوات المباشرة في البوت المدمج: lib:live يفتح المصدر الحقيقي (Xtream) مباشرة بدل
   بحث فارغ.
