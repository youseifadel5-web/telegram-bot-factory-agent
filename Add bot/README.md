# Add bot

هذا المجلد مخصص لإضافة بوتات/أنظمة جديدة لاحقًا بدون لمس الأنظمة الحالية.

## القاعدة
- كل بوت جديد يوضع في مجلد مستقل داخل `Add bot/`.
- لا تعدّل `cinema_core.py` أو `youseif_core.py` إلا عند الحاجة إلى جسر رسمي للواجهة/البحث.
- استخدم نفس الأسرار المشتركة من البيئة: `BOT_TOKEN`, `API_ID`, `API_HASH`, `ADMIN_ID`, `TMDB_API_KEY`.
- لا تضف Polling جديدًا. `main.py` هو الـpoller الوحيد.
- أي callbacks جديدة يجب أن تستخدم Prefix خاصًا بالبوت الجديد لتجنب التعارض.

## قالب الإضافة
انسخ `bot_template.py` وغيّر اسم الـprefix والوظائف، ثم اربط البوت في `main.py`.
